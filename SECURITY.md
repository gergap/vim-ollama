# Security Policy

## Project Status

This is a personal spare-time project provided free of charge.

While I try to fix security issues when time permits, I cannot guarantee:
- response times,
- security updates,
- regular maintenance, or
- long-term support.

There are no service level agreements (SLAs) or warranties.

If you intend to use this plugin in production or in a security-sensitive environment, you are responsible for evaluating whether it meets your security requirements.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please open a private GitHub Security Advisory if available, or contact me via GitHub.

Please include:
- affected version
- steps to reproduce
- impact assessment
- proof of concept, if possible

I will review reports as time permits, but I cannot guarantee a response or fix.

## Supported Versions

There are currently no maintained release branches. Security fixes, if provided, will generally only be made to the latest version of the project.
